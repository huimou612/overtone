01关于泛音

一个播放器外壳，
一颗会看歌词的芯。

泛音（Overtone）是一个二次开发作品。它把两个开源项目的长处缝在一起， 操作习惯沿用 LX Music，听歌的界面则交给 Folia 的视觉与 AI 能力。

点开「沉浸歌词」，歌词视觉、封面、播放控制与设置都收进同一个画面。 分词与音源分离全程在本机完成，音频不上传。它完全免费、开源，仅用于技术学习与交流， 不接受商业合作。

外壳 · Apache-2.0 LX Music

Electron + Vue 3 框架、播放器内核、播放列表、自定义源机制、桌面歌词窗口、数据同步、开放 API、主题系统

+
内核 · AGPL-3.0 Folia

海报墙 / 全屏歌词 / 时间线的交互与视觉，AI 歌词分词（逐词边界）、AI 凭据安全存储、音源分离（HTDemucs）

是什么
桌面音乐软件，以歌词视觉与本地 AI 能力为核心。
解决什么
让歌词、封面、控制与设置回到同一个沉浸画面。
适合谁
在意歌词呈现、想练唱或扒伴奏、希望本地播放的人。
02核心功能

一个画面，
装得下整首歌。

v0.4.0 把 Folia 视觉引擎完整带进桌面应用。右侧面板点一下就切换， 不用再打开第二个窗口。

01

15 种歌词视觉

商籁 / 凝彩 / 流光 / 心象 / 云阶 / 浮名 / 倾诉 / 回环 / 莫奈 / 时计 / 群唱 / 镜台 / 静止 / 绘光 / 花火。歌词与画面同时变化，逐字时间戳、 前奏与间奏保留当前行、宿主时间轴偏移全部对齐。

右侧「Folia 视觉效果」面板直接切换 · 实测无空白 / 错位 / 裁切

商籁凝彩流光心象云阶 浮名倾诉回环莫奈时计 群唱镜台静止绘光花火
02

6 种背景

通用 / 莫奈 / 漫游 / 隐现 / 嵌入 / 空，都在同一个面板里。 通用背景走封面取色 + 几何氛围层；莫奈支持封面或自定义图片、 半屏渐变或全屏叠色、自适应铺满。

WebGL2 已启用 · 3D / 着色器样式可用 · 不支持时优雅降级为文字样式

通用莫奈漫游隐现嵌入空
03

AI 逐字分词

用大模型把整行歌词切成词，为逐字高亮提供边界。结果写回本地库，重装不丢。

本机完成 · 结果持久化
04

音源分离

HTDemucs 跑在本地 Python sidecar，把一首歌拆成人声与伴奏，各导出一个文件。

音频不上传
05

凭据安全存储

API Key 交给 Electron safeStorage 加密（DPAPI / Keychain / libsecret），界面只显示「配没配」。

不落明文
06

搜索与播放

输入即出大词库联想（本地历史 + 热搜 + 在线补充）；本地音乐拖进列表即可播。

本地词库 · 自定义源

在线播放只走「自定义源」机制：本项目不提供、不托管、不推荐任何源，音频地址由使用者自行导入的源返回。

05使用指南

四步，
听到第一句逐字歌词。

安装后默认能播本地音乐。在线播放需要你自己导入「自定义源」—— 这是上游 LX Music 的开放机制，本项目不提供、不托管任何源。

完整 README FAQ
  1. 01

    安装

    从 Releases 下载 overtone-v0.4.0-x64-Setup.exe，覆盖安装即可，用户数据保留。macOS / Linux 包为历史版本提供且未签名。

  2. 02

    准备音乐

    把本地文件夹拖进列表即可播放。想听在线内容：设置 → 基本设置 → 自定义源 → 导入并选中。

  3. 03

    打开沉浸歌词

    点播放页的「沉浸歌词」进入同一画面，右侧面板切 15 种视觉与 6 种背景；按 P 开合面板，ESC 逐级退出，◀ ▶ 每次 ±100ms 微调时间轴偏移。

  4. 04

    按需开启 AI

    在侧栏「工作台」看状态、开能力：音源分离需先下载 HTDemucs 模型（约 200 MB），AI 分词需填你自己的 API Key。两项都在本机完成。

07开发者

仓库里，是怎么搭起来的。

桌面端基于 Electron 42 + Vue 3 + TypeScript，Webpack 多入口构建； 本站是与桌面端分开维护的零依赖静态页面。

overtone · stack 
$ overtone --stack

shell    electron 42+
ui       vue 3 · typescript
build    webpack · 4 entries
entries  main / renderer
           renderer-lyric
           renderer-scripts
runtime  node 18+ · python 3.8+
data     sqlite · overtone.data.db
base     lx-music + folia
license  agpl-3.0
status   v0.4.0 released

目录结构

  • src/common/IPC 契约唯一来源 ipcNames.ts
  • src/main/Electron 主进程模块与数据库 worker
  • src/renderer/主窗口 Vue 3 组件
  • src/renderer-lyric/桌面歌词窗口
  • src/renderer-scripts/自定义源沙箱
  • build-config/dev runner 与打包配置
  • docs/文档与真实界面截图

本地跑起来

$ npm install
$ npm run dev
$ npm run pack:win:setup

开发模式会同时编译四个入口，全部成功后才拉起 Electron 窗口。Windows 下若注入了 ELECTRON_RUN_AS_NODE=1，启动前需先去掉。
